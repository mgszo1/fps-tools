# 帧率小工具 1.0

用户目标：本地、免安装、中文图形界面，把全部原始视频帧按指定帧率播放；240 帧 / 30 fps = 8 秒。Mac（Apple Silicon / Intel）和 Windows x64 分别提供便携包。源文件不覆盖。

用户已选择方案 1 并要求直接做：保留容器格式和视频编码，画面不重编码、不插帧、不丢帧；音频跟随变速、保持音调，接受必要的高质量音频处理和重新编码。音频处理不声称数学无损。

## Approaches

采用 Qt/PySide6 原生桌面窗口 + 内置 FFmpeg stream copy/时间戳处理 + PyAV 检测校验。相比单独修改容器头，此方案能兼容更多容器并支持音频变速；相比浏览器版，大文件处理和离线分发更直接。音频使用 atempo 分段（每段 0.5–2 倍），不改变采样率来冒充变速。另一音频方案是允许改容器以存储无损音频，用户未选择。

## 行为

- 拖入 / 多选视频，显示源帧率、精确解码帧数、时长与目标时长；常见预设与有理数自定义帧率（1–240 fps）。23.976、29.97、59.94 预设用精确 NTSC 分数。
- 对恒定帧率文件变速；可变帧率、损坏文件、多个视频轨道、字幕/数据轨道等未支持情况明确拒绝，不静默丢弃。
- 支持候选容器 MP4/MOV/M4V/MKV/AVI/WebM；能否导出由视频编码复制、音频编码器与严格校验决定。无法通过则无成功输出。
- 视频采用 stream copy、重标定 PTS/DTS 和每包时长。按帧解码计数；编码包的顺序与 SHA-256、codec extradata、画面属性必须一致。目标时长按 N/fps，容器时间基容许量化误差。
- 音频尽量保留源编码，AAC 使用高码率；不支持的音频编码明确拒绝。同步保留音轨的相对延迟，并把音轨长度适配视频长度。视频不使用 -shortest 或全局 -t 截断。
- 后台任务、进度、取消、批处理逐项错误、避免覆盖、临时输出、校验通过后发布、同名自动编号。全离线，无上传与遥测。
- 发布包包含 Python、Qt、PyAV、FFmpeg；用户无需安装依赖。未配置开发者签名/公证时如实说明首次打开系统提示。

## 交付与验证

真实合成素材验证 24→30（240 帧/8 秒）、降帧率、NTSC、B 帧、无声/带声、非零起点、延迟音轨、多音轨、可变帧率拒绝、Unicode 路径、取消与不覆盖。用 440 Hz 正弦验证升/降速后音高。真实 GUI 截图与点击验收。三平台 CI 测试、打包、自包含 smoke test；GitHub Releases 提供下载。
