# FPS Tools Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox syntax for tracking.

**Goal:** Deliver a portable Mac/Windows graphical frame-rate conform tool with verified unchanged video and pitch-preserving audio.

**Architecture:** PySide6 UI calls a cancellable Python media service; bundled FFmpeg rewrites timing and processes audio; PyAV scans original/output frames and packet hashes. Publish only verified temporary output.

**Tech Stack:** Python 3.11, PySide6-Essentials, PyAV, imageio-ffmpeg, PyInstaller, pytest.

**Spec:** `docs/superpowers/specs/2026-11-10-fps-tools-design.md`

## Global Constraints

- Preserve original container extension and encoded video; never overwrite input.
- Audio tempo changes preserve pitch; audio encoding loss accepted by user.
- Local/offline, Chinese GUI, portable Mac arm64/x64 and Windows x64.
- Unsupported timing/streams fail explicitly. No silent fallback to video encoding.
- Rational targets 1–240 fps; output duration N/fps.

## Review Focus

- B frames: preserve PTS/DTS reordering and last frame (Task 1).
- Nonzero stream start and delayed audio: correct zero origin and synchronization (Task 1).
- VFR/damaged/extra tracks: refusal rather than misleading success (Task 1).
- Cancellation, preexisting destinations, Unicode paths: no partial files or overwrites (Tasks 1/2).
- Bundled binaries and platform startup: no developer environment dependency (Task 3).
